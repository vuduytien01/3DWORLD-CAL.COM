## Question

Cấu trúc code R3F của scene. Components nào, instancing dùng ở đâu, pipeline KTX2 và meshopt chạy thế nào trong build, và scene đọc trạng thái vé qua API engine bằng polling tần suất nào. Camera rig tự bám avatar theo pipeline từng bước kèm xoay và zoom chuột, chuyển cảnh khi đổi tầng. Ngân sách dưới 300 draw calls áp vào cấu trúc này thế nào.
